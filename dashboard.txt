# RBAC Dashboard

Roles
Admin
Sales (those who actually generate pdf)

## User flow

### Dashboard Rules

#### Admin access
- Can see the number of members active
- Can see the number of successfull pdf generated
- Can invite as admin or sales via
- Can delete any admin or sales

Constrainsts
- must have one active admin.

#### Sales Access
- Can generate a pdf.
- Can only see t  he number of pdf generated by them only.


## TechStack
Supabase for backend services.
Prisma ORM.
Typescript
Zod for client side validation
